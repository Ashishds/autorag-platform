# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The AutoRAG team takes security seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report the vulnerability privately via GitHub's **Security Advisories** feature:
1. Navigate to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Provide details including:
   - Type of vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested remediations

We will acknowledge receipt within 48 hours and work with you to remediate the issue promptly before public disclosure.
